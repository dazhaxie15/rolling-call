-----------

核心技术栈：
- Vue 3.5.24（组合式API + TypeScript）
- Three.js 0.170.0（3D渲染引擎）
- GSAP 3.12.7（高性能动画）
- Howler.js 2.2.4（音频管理）
- XLSX.js 0.18.5（Excel文件解析）

2. Canvas文本精灵
   ```typescript
   const createNameTexture = (name: string, color: string) => {
     const canvas = document.createElement('canvas');
     ctx.shadowColor = color;
     ctx.shadowBlur = 20;
     ctx.fillText(name, canvas.width / 2, canvas.height / 2);
     return new THREE.CanvasTexture(canvas);
   }
   ```

3. 随机抽取算法
   ```typescript
   const selectRandomStudents = (count: number): Student[] => {
     const available = [...students.value];
     for (let i = 0; i < count; i++) {
       const index = Math.floor(Math.random() * available.length);
       selected.push(available.splice(index, 1)[0]);
     }
     return selected;
   }
   ```

构建优化：

- 资源压缩（Gzip）
