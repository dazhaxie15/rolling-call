# 🔧 故障排除指南

## 问题：导入文件后无法开始点名

### 📋 症状
- 导入测试名单后
- 点击"开始点名"按钮
- 仍提示"请输入至少一个学生姓名或导入文件！"

### 🔍 排查步骤

#### 步骤1：使用基础诊断工具

1. 打开 `public/diagnostic.html`
2. 点击"运行完整诊断"
3. 查看测试结果
   - ✅ **所有测试通过** → 浏览器支持正常，继续步骤2
   - ❌ **测试失败** → 浏览器兼容性问题，请更换浏览器

#### 步骤2：使用文件导入测试工具

1. 打开 `public/file-test.html`
2. 测试文件导入功能
   - 点击上传区域或拖拽 `public/测试名单.txt`
   - 观察右侧"实时数据"区域
   - 查看底部"测试日志"

3. 查看日志中的关键信息：
   ```
   [SUCCESS] TXT文件读取成功
   [SUCCESS] 解析出 10 个姓名
   [SUCCESS] 姓名列表: ["张三", "李四", ...]
   ```

4. 如果数据正常显示：
   - `importedNames数组`: 包含文件中的姓名 ✅
   - `去重后`: 显示有效姓名列表 ✅
   - `是否可开始`: 显示"✅ 是" ✅

#### 步骤3：检查原应用的控制台

1. 打开 `src/index.html`
2. 按 `F12` 打开开发者工具
3. 点击 "Console" 标签
4. 导入文件，查看日志

**应该看到的日志：**
```
[DEBUG] 开始导入TXT文件: 测试名单.txt
[DEBUG] TXT文件导入完成，共 10 个姓名
[DEBUG] 当前importedNames: ["张三", "李四", ...]
[DEBUG] startApp函数被调用
[DEBUG] 合并后的所有姓名: ["张三", "李四", ...]
[SUCCESS] 可以开始点名 (共10个学生)
```

### 🚨 常见错误及解决方案

#### 错误1：文件读取失败
```
[ERROR] TXT文件读取失败
```
**原因：** 文件编码问题或文件损坏
**解决：**
- 确保文件编码为 UTF-8
- 使用系统自带的文本编辑器保存
- 尝试使用提供的测试名单文件

#### 错误2：数组为空
```
[ERROR] 没有有效的学生姓名
```
**原因：** 文件内容解析失败
**解决：**
- 检查文件格式是否正确（.txt 或 .csv）
- 确保每行一个姓名（TXT）
- 确保姓名在第一列（CSV）
- 检查是否有空行或特殊字符

#### 错误3：事件未绑定
```
[DEBUG] dragover监听器: ❌ 未绑定
```
**原因：** JavaScript 错误导致事件监听器未正确绑定
**解决：**
- 检查控制台是否有 JavaScript 错误
- 刷新页面重新加载
- 清除浏览器缓存（Cmd+Shift+R）

#### 错误4：DOM元素缺失
```
[ERROR] 文件列表容器不存在
```
**原因：** HTML 结构被破坏
**解决：**
- 检查 `src/index.html` 文件是否完整
- 确保没有部分内容被意外删除
- 从备份恢复文件

### 🛠️ 手动修复方法

如果工具检测到问题，可以尝试手动修复：

#### 方法1：清除浏览器数据
```javascript
// 在控制台执行
localStorage.clear();
location.reload();
```

#### 方法2：重置变量
```javascript
// 在控制台执行
importedNames = [];
manualNames = [];
isImporting = false;
console.log('变量已重置');
```

#### 方法3：强制刷新
- Windows/Linux: `Ctrl + F5`
- Mac: `Cmd + Shift + R`

### 💡 预防措施

1. **使用标准格式**
   - TXT文件：每行一个姓名，无空行
   - CSV文件：姓名在第一列，UTF-8编码

2. **浏览器要求**
   - 使用现代浏览器（Chrome 80+、Firefox 75+、Safari 13+）
   - 启用 JavaScript

3. **文件大小**
   - 单个文件建议小于 1MB
   - 学生人数建议不超过 200 人
