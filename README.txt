====================================
班级随机点名精灵 - 3D特效版
====================================

🎯 应用简介
-----------
一个基于Vue 3 + Three.js开发的3D魔法球随机点名应用。
特色功能：3D名字碎片球形特效、斐波那契分布算法、星空背景、音乐同步旋转。

✨ 核心特性
-----------
1. 3D魔法球特效
   - 名字碎片组成球形（Canvas文本精灵技术）
   - 斐波那契球面分布算法
   - 动态星空背景（2000+粒子）
   - 音乐同步旋转效果（待实现）

2. 名单管理
   - 支持Excel文件导入（.xls/.xlsx）
   - 支持CSV文件导入（.csv）
   - 支持TXT文件导入（.txt）
   - 支持手动输入
   - 自动去重和数据验证

3. 抽取功能
   - 随机抽取算法（公平公正）
   - 支持1-5人同时抽取
   - 抽取历史记录
   - 学生统计信息

4. 数据持久化
   - 本地存储（localStorage）
   - 自动保存
   - 数据导入导出

🚀 快速开始
-----------

方法一：右键打开（推荐 - Mac用户）
1. 右键点击 index.html 文件
2. 选择"打开方式" → "Safari" 或 "Chrome"
3. 应用自动在浏览器中打开

方法二：Python启动器（跨平台）
1. 确保已安装Python 3.6+
2. 双击运行 "一键启动器.py"
3. 或在终端中运行：python 一键启动器.py
4. 应用自动在浏览器中打开（http://localhost:8000）

方法三：Windows批处理
1. 双击运行 "启动点名精灵.bat"
2. 脚本自动检测Python并启动服务
3. 应用自动在浏览器中打开

📋 使用说明
-----------

第一步：导入学生名单
1. 点击"名单管理"按钮
2. 点击"导入名单"
3. 选择以下任一方式：
   - 文件导入：拖拽或点击上传Excel/CSV/TXT文件
   - 手动输入：在文本框中每行输入一个学生姓名
4. 点击"导入"按钮

支持的文件格式：
- TXT文件：每行一个姓名
  示例：
  张三
  李四
  王五

- CSV文件：逗号分隔的姓名列表
  示例：
  张三,李四,王五

- Excel文件：.xls 或 .xlsx，第一列为姓名
  示例：
  | 姓名   |
  |--------|
  | 张三   |
  | 李四   |
  | 王五   |

第二步：开始抽取
1. 返回主页
2. 选择抽取人数（1-5人）
3. 点击"开始抽取"按钮
4. 观察3D魔法球旋转动画
5. 抽取结果自动显示在底部

第三步：查看结果
1. 抽取完成后，被选中的学生会在底部高亮显示
2. 右侧卷轴显示历史记录
3. 名单管理页面可查看学生统计信息

🎮 操作指南
-----------

主界面控制：
- 名单管理：打开名单管理窗口
- 音乐：播放/停止背景音乐
- 抽取人数：选择1-5人
- 开始抽取：开始随机抽取
- 停止：中断抽取过程
- 清空结果：清除当前抽取结果

名单管理：
- 导入名单：打开导入窗口
- 删除学生：点击学生项右侧的删除按钮
- 统计信息：查看总人数、已抽取人数等

⚙️ 技术实现
-----------

前端技术栈：
- Vue 3.5.24（组合式API）
- TypeScript（类型安全）
- Three.js 0.170.0（3D渲染）
- GSAP 3.12.7（动画库）
- Howler.js 2.2.4（音频管理）
- XLSX.js 0.18.5（Excel解析）

核心算法：
1. 斐波那契球面分布
   - 在球面上均匀分布学生姓名
   - 黄金角螺旋分布算法
   - 确保视觉效果均衡美观

2. Canvas文本精灵
   - 动态生成文字纹理
   - 发光效果和透明处理
   - 高性能渲染

3. 随机抽取算法
   - Fisher-Yates洗牌算法
   - 保证抽取公平性
   - 支持不重复抽取

🐛 故障排除
-----------

问题1：双击index.html无法打开
原因：浏览器安全限制，禁止file://协议加载ES模块
解决：使用右键打开方式或Python启动器

问题2：3D效果卡顿
原因：设备性能不足或浏览器兼容性问题
解决：
- 关闭其他占用资源的程序
- 使用Chrome或Edge浏览器
- 更新显卡驱动

问题3：文件导入失败
原因：文件格式不支持或文件损坏
解决：
- 确认文件格式为.txt/.csv/.xls/.xlsx
- 检查文件是否损坏
- 尝试使用其他文件

问题4：Excel文件无法读取
原因：Excel文件有密码保护或格式不标准
解决：
- 确保Excel文件无密码
- 使用标准Excel格式
- 尝试另存为.xlsx格式
