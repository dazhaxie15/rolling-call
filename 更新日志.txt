🆕 新增功能

1. 文件导入功能

2. 用户界面优化
   ✅ 双栏布局：文件导入 + 手动输入

🔧 技术改进
-----------

1. 新增JavaScript函数
   - handleFileSelect() - 处理文件选择
   - processFile() - 通用文件处理
   - processCSVFile() - CSV文件解析
   - processTXTFile() - TXT文件解析
   - displayImportedFiles() - 显示导入结果
   - handleDragOver() - 拖拽悬停效果
   - handleDragLeave() - 拖拽离开效果
   - handleDrop() - 拖拽释放处理

2. 新增CSS样式
   - .file-upload-area - 文件上传区域样式
   - .file-upload-area.dragover - 拖拽悬停效果
   - .file-upload-icon - 上传图标
   - .file-upload-text - 上传提示文字
   - .file-upload-btn - 上传按钮
   - .file-list - 文件列表容器
   - .file-item - 单个文件项样式
   - .input-methods - 输入方式容器
   - .input-method - 单个输入方式

3. 文件处理流程
   - FileReader API读取文件
   - UTF-8编码支持
   - 逗号分隔CSV解析
   - 换行符分隔TXT解析
   - 数组去重算法
   - DOM操作更新UI

📝 使用方法
-----------

方式1：拖拽导入
1. 创建CSV或TXT文件，包含学生名单
2. 打开index-mac.html
3. 直接将文件拖拽到上传区域
4. 等待导入完成提示
5. 点击"开始使用"

方式2：点击选择
1. 打开index-mac.html
2. 点击"选择文件"按钮
3. 在文件选择器中选择CSV或TXT文件
4. 确认导入
5. 点击"开始使用"

方式3：混合输入
1. 导入文件获取大部分名单
2. 在文本框中手动补充剩余姓名
3. 系统自动合并并去重
4. 点击"开始使用"

📄 支持的文件格式
---------------

CSV格式：
- 逗号分隔
- 示例：
  张三,李四,王五
  赵六,孙七,周八
  吴九,郑十

TXT格式：
- 每行一个姓名
- 示例：
  张三
  李四
  王五
  赵六

编码要求：
- UTF-8编码
- 支持中文和英文
- 自动过滤空行

🚀 使用建议
-----------

1. 文件准备
   - 使用Excel创建名单
   - 另存为CSV格式（UTF-8编码）
   - 或直接创建TXT文件

2. 名单优化
   - 去除重复姓名
   - 确保编码为UTF-8
   - 每行/每个逗号分隔一个姓名

3. 导入技巧
   - 可先导入大部分名单
   - 再手动补充剩余姓名
   - 系统自动去重合并

4. 性能优化
   - 建议名单大小：5-500人
   - 超过1000人可能影响3D性能
   - 分批导入可提升流畅度

🔍 故障排除
-----------

问题：文件导入失败
解决：
- 检查文件格式（CSV/TXT）
- 确认文件未损坏
- 重新保存为UTF-8编码
- 检查文件大小

问题：中文显示乱码
解决：
- 使用Excel另存为UTF-8 CSV
- 或使用文本编辑器转换编码
- 确保文件编码为UTF-8

问题：拖拽无响应
解决：
- 使用"选择文件"按钮
- 尝试其他浏览器
- 检查文件是否在拖拽区域内

问题：导入速度慢
解决：
- 减少名单数量
- 分批导入大文件
- 关闭其他占用资源的应用

📞 技术支持
-----------

如遇问题：
1. 首先查看Mac使用说明.txt
2. 检查文件格式和编码
3. 尝试手动输入测试
4. 使用"选择文件"按钮代替拖拽

控制台调试：
- 打开浏览器开发者工具（F12）
- 查看Console选项卡
- 寻找错误信息

常见错误：
- "FileReader is not defined" → 浏览器不兼容
- "Invalid file type" → 文件格式不支持
- "Encoding error" → 文件编码问题
