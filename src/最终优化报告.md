### 1. ✅ 抽奖过程时长设定为6秒

**优化内容**：
- 将抽奖延迟时间从 1.5秒 延长至 **6秒**
- 6秒内球体旋转速度动态变化：
  - 前3秒：加速旋转（0.3 → 1.8倍速度）
  - 后3秒：减速旋转（1.8 → 0.3倍速度）
  - 使用缓动函数（easeInOut）实现平滑过渡

**代码实现**：
```javascript
const rollProgress = Math.min((Date.now() - rollStartTime) / 6000, 1);
const easeInOut = rollProgress < 0.5
  ? 2 * rollProgress * rollProgress
  : 1 - Math.pow(-2 * rollProgress + 2, 2) / 2;
rotationSpeed = 0.3 + easeInOut * 1.5;
```

### 3. ✅ 3D球体旋转效果优化

**参考小红书动画演示实现的改进**：

#### 🎯 多轴旋转系统
- **Y轴旋转**：主旋转轴，保持球体基本运动
- **X轴旋转**：上下倾斜，增加立体感
- **Z轴旋转**：左右翻转，丰富视觉效果

#### ⚡ 动态旋转速度
- **静止状态**：匀速旋转（0.3倍速）
- **抽奖状态**：
  - 6秒内速度从0.3 → 1.8 → 0.3
  - 使用二次缓动函数实现平滑加速和减速
  - 每个姓名碎片有独立的旋转相位差

#### 🔄 旋转矩阵计算
```javascript
// Y轴旋转
x = x*cosY - z*sinY;
z = x*sinY + z*cosY;

// X轴旋转
y = y*cosX - z*sinX;
z = y*sinX + z*cosX;

// Z轴旋转
x = x*cosZ - y*sinZ;
y = x*sinZ + y*cosZ;
```

#### ✨ 视觉效果增强
- **AdditiveBlending**：发光混合模式
- **多光源系统**：3个定向光源（主光、辅助光、顶光）
- **12种鲜艳色彩**：适合小学生的色彩搭配
- **多层渐变纹理**：文字带渐变和高光效果
