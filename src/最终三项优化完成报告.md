**优化内容**：

- TXT: `.txt`

**Excel文件处理逻辑**：
```javascript
// 使用SheetJS库读取Excel文件
const workbook = XLSX.read(data, { type: 'array' });
const firstSheetName = workbook.SheetNames[0];
const worksheet = workbook.Sheets[firstSheetName];
const jsonData = XLSX.utils.sheet_to_json(worksheet, { header: 1, raw: false });

// 提取第一列的姓名
const names = jsonData
  .map(row => row[0])
  .filter(name => name && typeof name === 'string' && name.trim())
  .map(name => name.trim());
```

**选中动画效果**：
```javascript
if (fragment.isSelected) {
  // 超大缩放
  const selectedScale = 3.5 + Math.sin(time * 6) * 0.5;
  fragment.mesh.scale.set(selectedScale, selectedScale, selectedScale);

  // 移动到屏幕中央
  const lerpFactor = 0.05;
  fragment.mesh.position.x += (0 - fragment.mesh.position.x) * lerpFactor;
  fragment.mesh.position.y += (0 - fragment.mesh.position.y) * lerpFactor;
  fragment.mesh.position.z += (5 - fragment.mesh.position.z) * lerpFactor;
}
```

**新增功能函数**：
