Mac用户专用 - 快速启动指南
====================================

🎯 问题解决
-----------
Mac上无法双击启动index.html的原因是：
浏览器安全限制，禁止从 file:// 协议加载 ES 模块。

✅ 解决方案
-----------

方案1：使用Mac专用版本（推荐）
--------------------------------
文件名：index-mac.html

特点：
✅ 无需安装任何软件
✅ 无需配置
✅ 可直接双击打开
✅ 完整的3D特效功能
✅ 支持名单输入和抽取

使用方法：
1. 双击 index-mac.html 文件
2. 系统自动用默认浏览器打开
3. 选择导入方式：

   📁 导入文件（推荐）：
   - 拖拽CSV/TXT文件到上传区域，或
   - 点击"选择文件"按钮选择文件
   - 支持格式：CSV（逗号分隔）、TXT（每行一个姓名）
   - 导入后自动填充到文本框

   ✍️ 手动输入：
   - 在文本框中每行输入一个学生姓名
   - 可与文件导入结合使用

4. 点击"开始使用"
5. 选择抽取人数（1-5人）
6. 点击"开始抽取"

方案2：右键打开（备用）
----------------------
文件名：index.html

使用方法：
1. 右键点击 index.html 文件
2. 选择"打开方式" → "Safari" 或 "Chrome"
3. 等待浏览器加载

注意：如果仍然无法打开，请使用方案1

方案3：Python启动器（高级）
-------------------------
如果需要完整功能（Excel导入等）：
1. 确保已安装Python 3.6+
2. 双击运行 "一键启动器.py"
3. 或在终端运行：python 一键启动器.py

🔧 故障排除
----------

问题1：双击后提示"无法打开"
解决：系统偏好设置 → 安全性与隐私 → 通用 → 允许从以下位置下载的应用
选择"App Store 和被认可的开发者"，或临时选择"任何来源"

问题2：显示空白页面
解决：
- 检查网络连接（需要加载Three.js CDN）
- 尝试使用Safari浏览器
- 确保JavaScript已启用

问题3：3D效果卡顿
解决：
- 关闭其他占用资源的应用
- 使用较新版本的Safari或Chrome
- 减少学生人数（建议不超过50人）

问题4：文字显示乱码
解决：确保使用UTF-8编码输入中文

问题5：文件导入失败
解决：
- 确认文件格式为CSV或TXT
- 检查文件是否损坏
- 尝试重新保存文件（确保UTF-8编码）
- 检查文件大小（建议不超过1MB）

问题6：拖拽文件无响应
解决：
- 确保使用受支持的浏览器（Safari/Chrome）
- 检查文件是否在拖拽区域内
- 尝试使用"选择文件"按钮代替拖拽

⚙️ 技术说明
-----------

Mac专用版本使用：
- 原生JavaScript（无ES模块）
- Three.js CDN（r128版本）
- Canvas 2D API（生成文字纹理）
- WebGL（3D渲染）
- CSS3动画

文件大小：
- index-mac.html: ~15KB（单文件）
- Three.js: 从CDN加载（~500KB）

网络要求：
- 首次加载需要网络连接（下载Three.js）
- 后续使用无需网络

📞 技术支持
-----------

如果遇到问题：
1. 首先尝试Mac专用版本（index-mac.html）
2. 检查浏览器是否支持WebGL
3. 确保网络连接正常（首次加载需要CDN）
4. 查看浏览器控制台是否有错误信息

控制台打开方式：
Safari: 菜单栏 → 开发 → 显示Web检查器
Chrome: 菜单栏 → 更多工具 → 开发者工具

常见错误：
- "THREE is not defined" → 网络连接问题或CDN加载失败
- 页面空白 → JavaScript被禁用或浏览器不兼容
- 3D效果卡顿 → 设备性能不足
