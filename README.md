# 班级随机点名精灵

一款面向小学教师的纯前端Web应用，通过童话魔法主题的3D交互和沉浸式音效，将课堂点名转化为趣味互动体验。

## 项目结构

```
rolling-call/
├── src/                    # 源代码
│   └── index.html         # 主应用文件（单文件架构）
├── dist/                  # 构建产物
│   └── assets/           # 静态资源
├── public/               # 公共资源
│   ├── diagnostic.html   # 🔍 基础诊断工具
│   ├── file-test.html    # 🧪 文件导入测试工具
│   ├── 测试名单.txt      # 📝 测试名单（TXT格式）
│   ├── 测试名单.csv      # 📝 测试名单（CSV格式）
│   ├── 故障排除指南.md   # 🔧 故障排除指南
│   ├── 修复报告.md       # 📋 修复报告
│   └── 3D旋转与音效升级报告.md # 🎬 3D与音效升级报告
├── README.md             # 📖 项目说明
├── 开发说明.md           # 💻 开发指南
└── PRD.md               # 📋 产品需求文档
```

## 快速开始

### 方法一：直接运行（推荐）

1. 用浏览器打开 `src/index.html` 文件
2. 即可开始使用

### 方法二：通过本地服务器

```bash
# 使用Python
cd rolling-call
python -m http.server 8080

# 或使用Node.js
npx serve .

# 然后访问 http://localhost:8080
```

### 🔍 故障排除工具

如果遇到文件导入或点名功能问题，请使用以下诊断工具：

1. **基础诊断工具**
   ```
   public/diagnostic.html
   ```
   - 检查浏览器API支持
   - 测试FileReader功能
   - 验证数组操作

2. **文件导入测试工具**
   ```
   public/file-test.html
   ```
   - 模拟真实文件导入场景
   - 实时显示数据处理过程
   - 提供详细日志

3. **测试名单文件**
   ```
   public/测试名单.txt
   public/测试名单.csv
   ```
   - 预制的测试数据
   - 用于验证导入功能

## 功能特性

- ✅ 3D魔法球点名系统（基于Three.js）
- ✅ 学生名单管理（支持手动输入和文件导入）
- ✅ 多种抽取模式（单人多人的随机抽取）
- ✅ 沉浸式音效系统（Web Audio API生成）
- ✅ 节奏感3D旋转动画（浮动+脉冲+场景旋转）
- ✅ 魔法主题UI设计
- ✅ 音效控制面板（开关+音量调节）
- ✅ 本地数据存储
- ✅ 响应式设计

## 技术栈

- **3D渲染**：Three.js
- **音效处理**：Howler.js
- **动画**：原生JavaScript + CSS3
- **构建**：Vite（生成dist目录）

## 开发说明

### 当前架构

本项目采用**单文件HTML架构**，所有应用逻辑、样式和组件都集成在 `src/index.html` 中。这种设计适合：
- 快速原型开发
- 简单功能迭代
- 无需构建步骤的开发调试

### 代码结构

`src/index.html` 文件包含：
- **HTML结构**：页面布局和组件
- **CSS样式**：魔法主题样式和3D特效
- **JavaScript逻辑**：
  - Three.js 3D场景管理
  - 学生名单管理
  - 点名抽取逻辑
  - 音效系统控制
  - 本地存储管理

### 修改和调试

1. **样式调整**：在 `src/index.html` 中的 `<style>` 标签内修改
2. **逻辑修改**：在 `<script>` 标签内修改JavaScript代码
3. **UI调整**：修改HTML结构和对应的CSS

### 未来升级

如需升级到Vue 3架构，请参考 `PRD.md` 中的技术实现方案。
